About this project

A live demonstration website showing how an interior design studio can present projects, services and a consultation form. It is a self-initiated demo built to showcase design and development approach, not commissioned client work. Sample photos are placeholders.

Key features

  • Project gallery
  • Service sections
  • Consultation request form
  • WhatsApp contact button
  • Mobile-first layout

This is a demo project created to showcase design and development capability. It is not presented as commissioned client work, and it does not show real client results.
